The evidence gap

Do not turn uncertainty into green.

A static match, an available scenario, an executed run, a control outcome, and live evidence are five different claims. AgentSec keeps them separate so “not tested” can never masquerade as a pass.

Risk is a reason to test

Read repository code and configuration without importing or executing it. A match may be verifiable, but it is not a verdict.

Evidence earns the claim
