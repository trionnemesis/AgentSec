The Attack–Detection Contract

Declare what good looks like.

An Attack–Detection Contract defines the attack, the blue-side expectations, and when each signal must arrive. One scenario asks four questions, so a green result has something precise to mean.

Write a contract ↗
01 / prevention

Did the agent refuse?

The unsafe action should be blocked by the control under test.

02 / detection

Did anyone see it?

Poll through the declared SLA; late or foreign-run signals cannot pass.

03 / evidence

Can we reconstruct it?

Every traced tool invocation needs its own correlated audit record.

04 / response

Did anyone act?

Judge the reaction by its event timestamp, not when it was collected.
