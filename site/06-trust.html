Safety boundaries

Keep the control surface narrow.

Targets come from an operator-owned allowlist. Production is not expressible. Live evidence must match the current run. The MCP gateway has no generic shell, SQL, arbitrary URL, or self-approval tool.

Read the security boundary ↗

Run provenance stays explicit: recorded, live, or mixed.

A static scanner finding is covered only when a scenario that declares both its surface and its threat class has actually produced a verdict; everything else stays not_tested.

not exposed

No generic capability

  • grant its own approval
