Role boundaries

Interfaces do not borrow authority.

Each layer does one job. Guidance does not grant permission, the host hook does not replace service policy, and a dashboard never recalculates the result.

Read the role decision ↗
Claude Code workbench

Inspect and present

Separates runtime code from development config, triages risks, locates fixes, and presents the read-only Live Artifact. It never decides the verdict.

MCP adapter

Project and delegate

Validates constrained schemas and delegates to the service. No shell, SQL, arbitrary URL, approval, or new policy.

single skill

Guide two lanes

Routes Red and Blue guidance. Static digest checks prove reviewed bytes, not model behaviour or permission.

host hook

Defend in depth

Rejects unsafe coding-agent tool requests. It is neither service policy nor evidence that a target control held.

deterministic core

Execute and decide

Owns allowlists, approvals, collection, four axes, precedence, persistence, and reporting queries.

Claude Code Live Artifact

Publish a snapshot

The session reads the local DTO and publishes self-contained HTML. The page never calls local MCP or exposes raw private evidence. This public site is separate.

Local HTML checks validate the Artifact source, not a real Claude Code client render. Desktop/Cowork #20 is a separate legacy optional-client check. Targets remain operator-owned, and live evidence must be correlated and timestamp-qualified.
