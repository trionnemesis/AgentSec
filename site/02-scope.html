Repository-first security

See what your repository exposes.

AgentSec classifies runtime agent code separately from development-agent configuration, then maps instructions, agents, skills, hooks, MCP servers, tool grants, and memory stores to ranked risks. It reads files; it does not import or execute the repository.

Explore the golden path ↗

Runtime presence is confirmed, likely, configuration_only, not_detected, or unsupported. None is a security grade. On current main, settings and default memory surfaces are verifiable; skills still has no covering scenario.
