agentsec init, agentsec scan, and the first dashboard read need nothing configured. They inventory and rank before anything runs. Dynamic verification is a separate, explicit action against an allowlisted target.

agentsec / terminal
$ pip install https://github.com/trionnemesis/AgentSec/releases/download/v0.4.4/agentsec-0.4.4-py3-none-any.whl
  # main is unreleased; pin a full reviewed commit SHA if evaluating it
$ agentsec init
$ agentsec scan
$ agentsec dashboard
  # optional dynamic verification after reviewing the risk and target
$ agentsec scan --verify --target order-agent-staging
$ agentsec dashboard
